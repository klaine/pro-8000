Installer

Installs PRO-8000 on a Behringer PRO-800 over USB, sets up its patch memory, or takes it back to the stock firmware. Works in Chrome or Edge on a computer.

Not connected

Before you start, connect the synth by USB and quit SynthTribe and anything else that uses MIDI, including MIDI patchbays and other MIDI pages in any browser: a single message from one of them makes the bootloader refuse an update. Editor tabs in this browser step aside by themselves.

Stock firmware file

Behringer's firmware can't be shared from this site, so it comes from your computer. SynthTribe downloads it when you run its Update once, even if the update stalls. On a Mac it's in ~/Library/Caches/com.behringer.synthtribe/fsCachedData/: a file of about 169 kB with a random name. Copy it somewhere and open it here; in Finder, Cmd+Shift+G goes to that folder. On Windows SynthTribe leaves no file: format the patch memory in the editor, then let SynthTribe flash stock itself (see the manual).
