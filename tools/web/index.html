Pro 800 Panel

Not connected. Needs Chrome or Edge (WebMIDI with SysEx) and firmware 0.1.6 or later.

Pots

Turn a knob: its card lights up. Type the knob's name (as printed on the panel) into that card. Names are saved in this browser as you type.

Switches

Inputs read directly by the MCU. Names are the schematic's net names; rename them if the panel says otherwise.

Buttons (HT16K33 key scan)

Press a button: the bits it sets turn green. Name the bit.

Encoder: 0 transitions (turn one detent to see how many it makes)

Display and LEDs (HT16K33 RAM)

Each square is one bit of display RAM. "Walk" lights one bit at a time: name what lights up (for example "digit 1 segment a", "SEQ1 LED", or "nothing"), then press Next.
